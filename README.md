<h1 align="center">

✨ Bienvenido a LocalUp

</h1>

<p align="center">

LocalUp es una plataforma web diseñada para promover el comercio local y facilitar el descubrimiento de lugares, negocios y eventos cercanos mediante una experiencia moderna, intuitiva y responsive.

</p>
